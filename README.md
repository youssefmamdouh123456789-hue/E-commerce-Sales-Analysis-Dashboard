# E-commerce Sales Analysis Dashboard

## 📊 Overview
An advanced, interactive Excel dashboard designed to provide a comprehensive analysis of e-commerce sales performance. This project transforms raw transactional data into actionable business insights, focusing on key performance indicators (KPIs), regional trends, and category profitability.

## 🚀 Key Features
* **Executive KPIs**: Instant visibility into Total Sales ($2.3M), Total Profit ($286K), Order Quantity (37,873), and Profit Margin (12.47%).
* **Growth Metrics**: Year-over-Year (YoY) growth tracking for all major KPIs with visual indicators.
* **Dynamic Visualizations**:
    * **Sales & Profit Analysis**: Monthly trend comparison of revenue vs. profitability.
    * **Category Wise Profit**: A waterfall chart breaking down profits across Technology, Office Supplies, and Furniture.
    * **Geographic Insights**: A map visualization showcasing sales distribution across the United States.
    * **Top 5 Subcategories**: Ranked analysis of products contributing most to revenue.
* **Interactive Slicers**: Filter the entire dashboard by Year (2011-2014), Region (Central, East, South, West), and Customer Segment (Consumer, Corporate, Home Office).

## 🛠️ Technical Stack
* **Tool**: Microsoft Excel
* **Features Used**: Pivot Tables, Advanced Formulas, Power Query (for data cleaning), Slicers, and Custom Charting.
* **Design**: Dark-themed professional UI for enhanced readability.

## 📂 Project Structure
* `ecommerce sales.xlsx`: The main project file containing the raw data, pivot tables, and the final dashboard.
* `README.md`: Project documentation.

## 📖 How to View
1. Clone this repository or download the `.xlsx` file.
2. Open the file in **Microsoft Excel 2016 or newer** (for full compatibility with slicers and map charts).
3. Interact with the **Filters** section on the bottom right to see data update in real-time.
